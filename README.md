# 元白诗笺 · 白居易 × 元稹 互文对照检索页

两位唐代诗人（白居易、元稹）诗句互文性的单页静态交互原型。纯原生 HTML/CSS/JavaScript，无框架、无构建步骤，可直接部署到 GitHub Pages。

## 文件结构

```
poem-intertextuality/
├── poem-intertextuality.html   # 页面本体（样式、交互逻辑内联）
├── data.js                     # 前端数据（由 CSV 生成，window.POEM_DATA）
├── 白居易-元稹.csv             # 原始互文数据（留存备查）
├── build_data.py               # 数据清洗脚本：CSV → data.js
├── assets/
│   ├── baijuyi.png             # 白居易立绘（AI 原创生成，透明背景）
│   └── yuanzhen.png            # 元稹立绘（AI 原创生成，透明背景）
├── _backup/                    # 早期占位原型备份，不参与交付
└── README.md
```

## 本地运行

直接双击 `poem-intertextuality.html` 用浏览器打开即可；或在本目录起静态服务：

```bash
python -m http.server 8000
# 浏览器访问 http://localhost:8000/poem-intertextuality.html
```

## 部署到 GitHub

1. 新建仓库，将本目录（含 `data.js`、`assets/`）整体推送：

```bash
git init
git add .
git commit -m "元白互文对照检索页"
git branch -M main
git remote add origin <你的仓库地址>
git push -u origin main
```

2. 仓库 **Settings → Pages → Source** 选择 `main` 分支、根目录。
3. 若希望仓库根目录直接作为入口，可将 `poem-intertextuality.html` 重命名为 `index.html`（同步修改内部引用即可）。

## 功能

- **关键词检索**：匹配诗句、诗题中的字词
- **常用词快捷检索**：检索框下方提供数据集中高频出现的双字词，点击即填入并检索
- **强度筛选**：全部 / ≥8000 / ≥9000 三档互文分值
- **双侧对照**：左白居易、右元稹，对话框显示当前配对诗句
- **候选联动**：点击一侧诗句，另一侧自动切换到其最高分配对；候选列表按分值降序
- **分值标注**：≥9000 高度重合，8000–8999 中等关联，其余弱相关
- **关键词高亮**：命中字词在诗句中标注
- **响应式**：宽屏左右对照，窄屏上下堆叠

## 数据说明

原始 CSV 共 11 列：

| 列 | 内容 |
|---|---|
| 1 | 诗人甲（白居易） |
| 2 | 甲诗名 |
| 3 | 甲诗句 |
| 4 | 诗人乙（元稹） |
| 5 | 乙诗名 |
| 6 | 乙诗句 |
| 7 | 互文性得分（7000–10000，越高越相关） |
| 8–11 | 诗名 / 诗句编码（经核对与诗句非一一对应，未作为节点键使用） |

清洗规则（见 `build_data.py`）：
- 以「诗名 + 诗句」去重生成节点；同一句对重复记录保留最高分
- 输出 `data.js`：`nodesA` / `nodesB` 为 `[诗名, 诗句]` 数组，`edges` 为 `[白句id, 元句id, 得分]` 三元组

**数据未包含体裁、主题、年代、地点、事件、典故分类**，因此页面未设置相应筛选与标注，也未据外部资料补填，以保证信息准确。

## 重新生成数据

替换 CSV 后，在本目录运行：

```bash
python build_data.py
```

脚本会覆盖 `data.js` 并输出节点与配对数量。
